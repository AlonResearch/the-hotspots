# Local basemap

Natural Earth 1:50m land, country boundary lines (land) and lakes, public domain
(https://www.naturalearthdata.com/, files from github.com/nvkelso/natural-earth-vector).
Properties removed and coordinates rounded to 3 decimals to keep the files small.
Used when the online basemap does not load within 4 s, or with `VITE_BASEMAP=local`.
